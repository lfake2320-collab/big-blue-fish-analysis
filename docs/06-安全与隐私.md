# 06｜安全与隐私：哪些东西绝对不要上传

**本仓库当前是公开仓库（Public）。任何人都可能访问。**上传前要把它当作公开发布，而不是私人网盘。

## 不要上传

- OpenAI API Key、Runtime API Key、GitHub Token
- 密码、Cookie、登录凭据、OAuth Token
- Tunnel 私钥、密钥文件、完整凭据配置
- 个人聊天记录、账号信息、个人身份资料
- 大肥鱼原始 EXE、完整安装目录、完整 app.asar（除非已确认有权公开发布且确有必要）
- 本机数据库、会话数据、缓存、浏览器用户数据
- 未清理的调试日志和崩溃转储
- 第三方软件、模型权重、音频样本等未经许可的资源

## 可以考虑上传

- 自己撰写的分析说明
- 不含密钥的环境搭建步骤
- 已清理的目录树
- 不含个人信息的工具输出摘要
- 自己编写且不含敏感信息的辅助脚本
- 对公开技术资料的简要说明和来源链接

## 上传前检查

1. 搜索 `sk-`、`token`、`password`、`secret`、`cookie` 等可疑字符串。
2. 检查日志是否包含请求头、授权信息或用户数据。
3. 检查脚本是否把密钥写死在文件里。
4. 确认第三方程序和资源的版权许可。
5. 牢记删除 GitHub 当前文件不一定会从历史提交中清除秘密。如果密钥曾经提交过，应立即撤销密钥，并按需要清理 Git 历史。

## 如果密钥泄露怎么办？

- 立即在对应服务中撤销泄露的密钥。
- 检查最近的调用记录和账单。
- 创建权限最小的新密钥。
- 使用安全提示或环境变量输入，不要写进代码或仓库。

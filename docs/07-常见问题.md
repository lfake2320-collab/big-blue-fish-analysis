# 07｜常见问题：用大白话解释

## EXE 是什么？

EXE 就是 Windows 可以直接运行的程序文件。但桌面应用的功能不一定都写在 EXE 里面，旁边的资源文件可能才包含大部分业务代码。

## Electron 是什么？

Electron 可以理解成“把网页技术装进桌面软件”。开发者用 HTML、CSS、JavaScript 做界面，再用 Electron 提供桌面窗口、文件访问等能力。很多聊天工具和编辑器都使用它。

## app.asar 是什么？

它像一个打包好的应用资源包，里面可能放着 JavaScript、页面、配置和其他文件。它不是普通文件夹，需要用合适的工具查看或解包。解包前最好先复制一份，别破坏原文件。

## Node.js 是什么？

它让 JavaScript 不只在浏览器里运行，也能在电脑本地执行程序、读写文件、启动服务等。

## Ghidra 是什么？

它是一个反汇编和反编译工具。程序编译后变成机器码，人很难直接读。Ghidra 尝试把机器码还原成更容易理解的结构和伪代码。还原结果不一定等于原始源码。

## REA 是什么？

REA 是这里使用的分析工具集合，并通过 MCP 让 ChatGPT 可以调用。它像一个“本机工具箱”，真正执行检查的是本机 REA 及其 Provider。

## MCP 是什么？

MCP 是一种让 AI 调用外部工具的通信方式。可以理解成给 AI 接了一套标准插座：AI 发出工具请求，本地服务执行，再把结果返回。

## Tunnel 是什么？

Tunnel 是一条连接通道。这里由本机客户端主动连接 OpenAI 的隧道服务，再把 ChatGPT 的请求转给本机 REA。它不是把电脑的整个硬盘公开到互联网。

## 静态分析和动态分析有什么区别？

- 静态分析：不运行程序，直接查看文件、字符串、依赖、代码结构。
- 动态分析：运行程序，观察它实际做了什么，例如启动了哪些进程、访问了哪些文件、调用了哪些接口。

两种方式结合起来，结论才更可靠。

## DLL 是什么？

DLL 是 Windows 的动态链接库。程序可以调用 DLL 提供的功能。某个 DLL 出现在导入表里，只说明程序有相关依赖或引用，不代表每个功能都会在实际运行中调用。

## 为什么不能光看文件名就下结论？

文件名可能误导人。一个叫 voice 的文件不一定负责 QQ 语音；一个叫 session 的文件也不一定就是会话恢复入口。必须沿着代码调用关系和实际运行行为验证。

## 为什么仓库里没有 EXE 和 ASAR？

它们可能很大，也可能包含第三方代码、资源或用户数据。仓库当前主要保存分析笔记和方法，避免不必要地公开程序本体。

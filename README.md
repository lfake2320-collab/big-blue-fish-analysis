## 记录规则

每条分析结论都尽量标注状态：

- **已验证**：有实际工具返回、命令输出或文件内容支持。
- **初步线索**：看到了相关迹象，但还没追到实际执行过程。
- **待复核**：之前有人提到，但当前仓库没有保留足够证据。
- **未开始**：还没有真正检查。

不要把“程序导入了某个 DLL”说成“程序一定在使用某个功能”；不要把“目录里有某个组件”说成“某功能已经成功运行”。
